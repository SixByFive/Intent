## Description

`packages/cli` command handlers do exactly three things: resolve the git root, call a `core` function, format and print the result. `packages/mcp` tool handlers do the same. No business logic — no filtering, scoring, parsing, or file I/O — lives in either package.

## Rationale

This constraint is what makes the CLI and MCP server behaviour identical without duplication. If logic creeps into CLI handlers it becomes untestable in isolation and invisible to MCP consumers (see DEC-0004). Violations are easy to spot in code review: any `if`, loop, or fs call in a CLI command handler is a smell.
