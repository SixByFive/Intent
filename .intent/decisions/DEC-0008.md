## Context

The `--watch` flag on `intent export` needs to monitor `.intent/` subdirectories for changes and re-export. `chokidar` is the standard Node.js file-watching library and handles cross-platform edge cases well. However, it is a substantial dependency (pulls in glob, braces, picomatch, etc.).

Node.js 18+ ships `fs.watch` with the `{ recursive: true }` option natively, but `recursive` is only reliable on Windows and macOS (not Linux) until Node 22. Watching each subdirectory individually (`plans/`, `decisions/`, `systems/`, `constraints/`) works on all Node 18+ platforms without recursive.

## Decision

Use Node.js built-in `fs.watch` with one watcher per `.intent/` subdirectory. A 250ms debounce prevents redundant re-exports when multiple files change in quick succession. The watcher ignores `links/index.json` and `.agent-session.json` to avoid export loops.

## Consequences

- Zero new runtime dependencies — Node.js built-ins only (consistent with CON-0002)
- Works on Node 18+ on all platforms
- Watchers are returned as a `WatchHandle` with a `stop()` method so the CLI can clean up on SIGINT
- Does not detect new subdirectories created after watch starts (acceptable — `.intent/` subdirectories are created at `intent init` time)
