## Context

Context tools often require a backend, a sync service, or a SaaS account. This creates friction (onboarding, cost, network dependency) and means context is decoupled from the code that triggered it.

## Decision

`.intent/` is committed alongside code in the same git repository. No external database, no API, no account required. The links index (`.intent/links/`) is the only generated artifact and is excluded from git.

## Consequences

- Works offline, works in CI, works in any environment with git
- Intent context versions with the code — you can `git log` or `git blame` reasoning
- No migration path needed when changing tools — it's just files
- No central index means `intent link` must be run to rebuild the index after changes
